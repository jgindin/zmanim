# The bundled geoid grid

`Zmanim/src/main/assets/geoid/geoid.bin` lets the app turn a GPS altitude into a height above sea
level with no network connection. It is generated by the `:Zmanim:generateGeoidGrid` task and
committed, so builds never download anything. The format is described in
`build-logic/.../geoid/GeoidGridData.kt`.

## Why the app needs it

`Location.getAltitude()` is the height above the WGS 84 ellipsoid. The zmanim are computed from the
height above sea level, and the two differ by the geoid height: about +20 m in Jerusalem, +46 m in
London and -33 m in New York. Android reports the height above sea level itself
(`Location.getMslAltitudeMeters()`) only from API 34; on older devices the app subtracts the geoid
height from this grid.

## Source and license

- **Data:** EGM2008, the US National Geospatial-Intelligence Agency's Earth Gravitational Model, as
  the 5-minute geoid grid GeographicLib publishes (`egm2008-5`), from
  <https://geographiclib.sourceforge.io/C++/doc/geoid.html>.
- **Downloaded:** 2026-11-08. The checksum is in `geoid-pins.tsv`.
- **License:** public domain (a work of the US government; listed as public domain by PROJ-data,
  <https://github.com/OSGeo/PROJ-data/blob/master/us_nga/us_nga_README.txt>). No attribution is
  required; `NOTICE` and the asset's second line name the source anyway.

## What the generator changes

- **Nodes kept:** one every whole degree of latitude and longitude, 181 rows by 360 columns,
  sampled from the source's nodes, not averaged. 130,496 bytes, about 80 KB compressed in the APK.
- **Precision:** each height is rounded to the nearest decimeter.
- **Accuracy:** checked against the 5-minute grid at 40,000 random points spread evenly over the
  globe, with the bilinear interpolation the app uses:
  - The median error is 0.1 m, 95% of points are within 1.0 m, and 99% are within 2.3 m.
  - The worst point found was 10.4 m, in steep terrain.
  - At 18 well-known cities, the worst is 2.0 m.

  GPS altitude is itself only good to 5 to 15 m, so a finer grid would not make the result better.

## Regenerating

```bash
./gradlew :Zmanim:generateGeoidGrid --rerun
```

`--rerun` is needed because the task is otherwise up to date when its output exists. The run reuses
the file in `Zmanim/build/geoid/downloads` when its checksum matches, and downloads it otherwise.
GeographicLib has not changed this file since 2009, so a different checksum means something is
wrong, not that there is newer data: check before changing the pin.
